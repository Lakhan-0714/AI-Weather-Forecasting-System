# 🌦️ AI Weather Forecasting System

An AI-powered Weather Forecasting Web Application built using Flask, Python, WeatherAPI, HTML, CSS, and JavaScript.

## 🚀 Live Demo
https://ai-weather-forecasting-system.onrender.com

## 📂 GitHub Repository
https://github.com/Lakhan-0714/AI-Weather-Forecasting-System

## 📌 Features

- Real-time Weather Forecast
- City Search Functionality
- Temperature Information
- Humidity Monitoring
- Wind Speed Details
- UV Index Information
- Weather Alerts
- Voice Search Support
- Responsive User Interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- WeatherAPI
- GitHub
- Render

## ⚙️ Installation

```bash
git clone https://github.com/Lakhan-0714/AI-Weather-Forecasting-System.git

cd AI-Weather-Forecasting-System

pip install -r requirements.txt

python app.py
```
